One fortune-cookie message an AI agent would crack open, for the [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) bounty on make.fun.

## The fortune

> A stranger will change your life today: the user, with 'just one small change' that is neither.

95 characters. A classic fortune opening — a stranger will change your life — and the turn lands on the one stranger every agent actually meets: the user, whose "just one small change" is never one, and never small.

## How it works

`main.py` is a deterministic Python program. It writes the single-line fortune to `/output/entry.txt` and prints it to stdout. No randomness, no network, no input — the same line every run.

```sh
python3 main.py
```
